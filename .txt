# 8. Role Middleware — COMPLETED

File:

```text
middleware/role.middleware.ts
```

Purpose:

```text
allowRoles()
```

Example:

```ts
allowRoles("admin")
```

means:

> Only admin can access this route.

Example:

```ts
allowRoles("client", "guest")
```

means:

> Client OR guest can access this route.

The concept is:

```text
identifyUser()
        ↓
req.user.role
        ↓
allowRoles("admin")
        ↓
permission check
```

Important:

`allowRoles("admin")` is NOT authentication.

`identifyUser()` identifies the logged-in user.

`allowRoles()` checks whether that user has permission.

# 14. Important Admin Testing Discovery

At first, `POST /api/food` returned:

```text
Access denied
```

We discovered the reason:

The logged-in user's MongoDB role was:

```text
client
```

while the route required:

```ts
allowRoles("admin")
```

After changing the database user's role to:

```text
admin
```

and logging in again, creating food worked.

This proved the role middleware is working.

Important lesson:

If database role changes from:

```text
client → admin
```

the old JWT still contains:

```text
role: client
```

So the user must login again to get a new JWT containing:

```text
role: admin
```

createAdmin code =>

import mongoose from "mongoose";
import bcrypt from "bcrypt";
import { userModel } from "../models/user.model.js";

const createAdmin = async () => {
    try {
        await mongoose.connect(process.env.MONGO_URI!);

        const email = "admin@cafe.com";
        const username = "admin";
        const password = "Admin@123";

        const existingAdmin = await userModel.findOne({
            email
        });

        if (existingAdmin) {
            console.log("Admin already exists");
            process.exit(0);
        }

        const hashedPassword = await bcrypt.hash(password, 10);

        const admin = await userModel.create({
            username,
            email,
            password: hashedPassword,
            role: "admin"
        });

        console.log("Admin created successfully");
        console.log({
            email: admin.email,
            username: admin.username,
            role: admin.role
        });

        process.exit(0);

    } catch (error) {
        console.error("Failed to create admin:", error);
        process.exit(1);
    }
};

createAdmin();
