# Cafe Project - Development Context

## Project Overview

I am building a full-stack Cafe Order Management System.

Goal:

* Customers can view food items and place orders.
* Customers can continue as registered users or temporary guests.
* Admin can manage food and orders.
* Learning project while building with TypeScript + React + Node.js.

* React + TypeScript (currently learning and building)

---

## 2. Guest Authentication ✅

Created:

guestUser.controller.ts

Guest is NOT stored in database.

Guest flow:

```
Guest Login
      |
Generate guestId using crypto.randomUUID()
      |
Create JWT
      |
Store token in cookie
      |
Token expires after 5 hours
```

Guest JWT example:

```json
{
    "role":"guest",
    "guestId":"unique-id"
}
```

---

# Authentication Middleware

Current middleware:

identifyUser()

Purpose:

* Read JWT from cookie
* Verify token
* Attach user information to req.user

Important:

Middleware supports:

```ts
role:
"client" | "admin" | "guest"
```

Current Request type:

```ts
req.user = {
    id?,
    username?,
    guestId?,
    role
}
```
